Seat Reservation — part of Smart Library Management System

1. Project overview
The Smart Library Seat Reservation System is a standalone, role-based web application that allows students to discover, book, and occupy library seats through a structured pipeline. Librarians manage physical zones and seats, verify student arrivals via QR scan, and handle day-to-day operations. Administrators control the full configuration including user accounts, zone setup, and reporting.
The system is designed as a self-contained module that can be integrated into a broader library management platform via a REST API.

1.1 Goals
    • Eliminate seat conflicts and double-bookings through enforced reservation rules.
    • Give students real-time seat availability across all zones.
    • Replace manual sign-in sheets with a QR-based check-in/check-out system.
